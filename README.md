# Auralis Multimodal Annotation

专业视听多模态数据清洗与标注平台演示，覆盖数据清洗、交互式分割、目标检测、跨帧跟踪、音视频对齐、字幕生成及二次质检。

## 在线演示

https://yixuan-wang1.github.io/auralis-multimodal-annotation/

## 功能

- 视频、音频、图像与文本资产管理
- SAM 2 交互式分割与 Track Anything 跨帧跟踪
- YOLOv11 目标检测与实例管理
- WhisperX、AV-HuBERT 音视频事件对齐
- 多模态区域描述生成与人工修订
- 数据清洗、质量审核和算法流水线管理
